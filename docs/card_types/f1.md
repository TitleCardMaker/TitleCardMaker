# Formula 1 Card Type

This card design was created by [CollinHeist](https://github.com/CollinHeist) and
[/u/heeisenbeerg](https://www.reddit.com/user/heeisenbeerg).

This card type is designed specifically for displaying race details for Formula
1. It features a country flag banner on the left side, a frame overlay with the
race year, and Formula 1-styled typography. The card automatically selects the
appropriate flag based on the season title (e.g., "Japanese" for the Japanese
Grand Prix), making it ideal for Formula 1 series with custom season titles.

!!! tip "Series Compatibility"

    This card type is specifically designed for Formula 1 content and is not
    widely applicable for non-F1 series. It works best when custom season titles
    are set to match the country/flag of each race (e.g., "Japanese", "British",
    "Monaco", etc.).

## Country / Flag Selection

The country flag displayed on the left side of the card can be automatically
determined from the season title, or manually specified with the _Country_
extra. Supported countries include: Abu Dhabi, Australian, Austrian, Azerbaijan,
Bahrain, Belgian, British, Canadian, Chinese, Dutch, Hungarian, Italian,
Japanese, Las Vegas, Mexican, Miami, Monaco, Qatar, Sao Paulo, Saudi Arabian,
Singapore, Spanish, United Arab Emirates, and United States.

If no match is found, a generic flag is used.

## Race Name

The race name is displayed prominently in the center of the card, above the
title text. By default, this is set to "GRAND PRIX", but can be customized with
the _Race Name_ extra. This is useful for special race types other than the
Grand Prix.

??? example "Example"

    <div class="image-compare example-card"
        data-starting-point="65.57"
        data-left-label="SPRINT"
        data-right-label="GRAND PRIX">
        <img src="../assets/f1/race_name.webp"/>
        <img src="../assets/f1.webp"/>
    </div>

## Episode Text

The episode text (which typically displays the round number, e.g., "ROUND 16")
can be customized in several ways.

### Color

The color of the episode text can be adjusted with the _Episode Text Color_
extra.

??? example "Example"

    <div class="image-compare example-card"
        data-starting-point="54"
        data-left-label="rgb(233,20,35)"
        data-right-label="white">
        <img src="../assets/f1/episode_text_color.webp"/>
        <img src="../assets/f1.webp"/>
    </div>

### Font Size

The size of the episode text can be adjusted with the _Episode Text Font Size_
extra. Like all font sizes, values greater than `#!yaml 1.0` will increase the
size of the text, and values less than `#!yaml 1.0` will decrease it.

??? example "Example"

    <div class="image-compare example-card"
        data-starting-point="56.6"
        data-left-label="1.3"
        data-right-label="1.0">
        <img src="../assets/f1/episode_text_font_size.webp"/>
        <img src="../assets/f1.webp"/>
    </div>

## Frame Year

The year displayed in the bottom-right corner of the frame can be adjusted with
the _Frame Year_ extra. By default, this is automatically set to the year the
episode aired, or `2026` if that information is not available.

??? example "Example"

    <div class="image-compare example-card"
        data-starting-point="33.0"
        data-left-label="2025"
        data-right-label="2024">
        <img src="../assets/f1/frame_year.webp"/>
        <img src="../assets/f1.webp"/>
    </div>

## Custom Flag File

A custom flag file can be specified with the _Flag_ extra. If provided, this
will override the automatic country flag selection. The file path should point
to a valid image file that will be used as the flag banner on the left side of
the card. The dimensions should match that of the builtin banner files, as
TCM will not do any automatic resizing.

!!! note "Flag File Requirements"

    If a custom flag file is specified but does not exist, the card will fall
    back to the automatic country flag selection based on the season title or
    country extra.

## Mask Images

This card also natively supports [mask images](../user_guide/mask_images.md).
Like all mask images, TCM will automatically search for alongside the input
Source Image in the Series' source directory, and apply this atop all other Card
effects.
