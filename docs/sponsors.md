# Sponsors

The development of the TitleCardMaker Web UI was made possible by the extremely
generous support of project Sponsors.

For those who wish to continue to support the project (even after the public
release of the UI), you may sponsor the project on GitHub and get access
features and changes as they're being developed. Sponsors will be able to make
requests for new features, card types, as well as receive priority support for
all parts of the project.

With each major release, the Sponsors-only changes will be publicly released to
non-Sponsors - depending on the magnitude of changes, this is expected to occur
every few months.

If you are interested in supporting the project, please see
[here](https://github.com/sponsors/CollinHeist/).

Thank you!
