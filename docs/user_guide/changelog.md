# Changelog

TitleCardMaker's release notes and version history live inside the Web UI.

1. Open TitleCardMaker in your browser.
2. Navigate to `Settings` > `System`, or go directly to the `/changelog` URL.
3. Browse releases by version; the currently running version is linked from the
System Summary page.

!!! tip "Staying Updated"

    Docker users on the `latest` tag pick up stable releases when they pull a
    new image. The `develop` tag tracks in-progress changes and may include
    unfinished features — see [Selecting a Branch / Tag](./index.md#selecting-a-branch-tag).
