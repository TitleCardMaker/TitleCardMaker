# Translation

## Background

TitleCardMaker has the ability to look up translations of a title in a given
language on TMDb. For example, rather than displaying titles in English, it is
possible to configure TCM so that the titles appear in French (for example).

In addition to this feature, which all card types support, the
[Anime](./card_types/anime.md) card type also allows for displaying the
Japanese titles (as kanji) on the card.

In order to use this setting, [TMDB](./prefs/tmdb.md) __must__ be enabled.
